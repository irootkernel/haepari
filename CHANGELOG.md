# Changelog

## v0.1.1 - Unreleased

### Changed

- Pin developer Go, CPython and uv through one manifest and an explicit user-cache bootstrap; group dependency preparation, formatting, static/build checks and documentation generation under test preparation and carry portable toolchain snapshots and verified build metadata with examples and release archives.

### Fixed

- Identify the failed Job, validation stage and safe cause category in supplementary recovery refusals without exposing raw backend errors or changing error/exit/retry semantics.
- Export immutable results, gaps and verified files when an explicitly uncollected guest log has no host file or durable binding; continue refusing lost, changed or unexplained evidence.

- Bind new guest preparations to descriptor-observed volume UUID, 64-bit file ID and creation time using new guest/control/recovery contracts and explicit capabilities; preserve historical wire bytes, digests and replay, verify original evidence before cross-boot recovery, and reject replaced or legacy unidentified objects.

- Allow a resource recollect plan to select one owned retained Job with `--job-id`, preserving target-bound replay, finite deadlines and global safety fences while unresolved peers continue to block reuse.
- Keep VM Job recovery plans stable across observation-only SSH measurements while retaining audit history and revision, lease, ownership and native-evidence fences. Historical VM Job plans retain `haepari.recovery-plan/v4`; plans carrying prepared identity use v5. Operator attestation still cannot produce PASS.

## v0.1.0 - 2026-10-22

### Added

- Support automatic Jobs and manual Jobs with recorded human observations on macOS arm64 local resources and one already-running registered persistent UTM macOS VM, without issuing VM power commands.
- Provide closed, versioned JSON contracts and explicit workload, evidence, cleanup and final-verdict reporting for CLI integrations.
- Seal selected-file inputs and raw environment profiles, with reusable project-test helpers and a separate guarded guest entrypoint.
- Persist FIFO queues, capacity leases, immutable request keys and terminal results, with same-key replay, blocking observation and explicit cancellation.
- Supervise workloads independently of callers, reconnect to original executions after SSH or controller interruption, and require proof-bound recovery before reusing uncertain resources.
- Collect bounded logs and hashed artifacts with paged reads, explicit evidence gaps, verified export and retention/purge guards that preserve protected evidence and admission identities.
- Coordinate cooperating tools with durable advisory locks, bounded renewal and expiry, and read-only nested-borrower validation.
- Expose bounded controller configuration, resource-readiness checks and queue/retention diagnostics while preserving occupied or quarantined resources when execution or cleanup is uncertain.
- Ship a checksummed macOS arm64 archive with a standalone ad-hoc-signed executable, the `use-haepari` skill, portable examples, a complete-tree verifier, the MIT license, applicable third-party notices and explicit per-user release-service setup.
